My take on an MCP server for a cannabis ERP.

I wanted to explore how AI assistants could work with an ERP in practice, so I built my own version on fictional data. Along the way I added a few things I'd want as an operator: an approval step on the server, an audit log, and labels showing which actions reach Metrc or QuickBooks. Connect it to Claude and try it.

1. Approval the server controls

Write tools can only request a change. There is no approve tool, so no assistant can approve its own work. A person approves here, with a before-and-after preview.

2. An audit log of every call

Every read, request, approval and applied change is recorded: who, which tool, which systems, and what changed.

3. Labels on what leaves the ERP

Each tool declares whether it reads or writes, and whether it reaches QuickBooks, Metrc or email. Anything reported to the state needs an extra acknowledgement.

Why I added those pieces

The same answer in every AI clientApproval happens on the server, so the AI can't change records on its own, whichever assistant someone connects.
Room to add more write actionsWith a person approving on the server, new write tools can be tried with less risk.
Comfort for compliance teamsAnything reported to the state is labelled, explained and acknowledged by a named person.
"Who did that?" in one clickThe audit log shows which person, which assistant, which tool and what changed.
A natural premium featureApproval rules and audit history are the kind of controls larger customers ask for and pay for.
Product signalEvery request, approval and rejection shows which actions people trust, and where it's safe to auto-approve next.

The trade-off is one extra step per write. Approval rules (e.g. auto-approve small payments for some roles), batch approval, and approving inside the ERP or in Slack would remove most of it.

Connect it to Claude

  1. In Claude, open Settings → Connectors → Add custom connector.
  2. Name it Wholesale Ops demo and paste the URL above. No sign-in needed: it's a public demo on fictional data.
  3. Start a new chat and try one of the prompts below. Keep this page open to approve.

No Claude handy? There's already an action waiting below. Review and approve it, then see the balance change on the Data page and the steps in the audit log.
